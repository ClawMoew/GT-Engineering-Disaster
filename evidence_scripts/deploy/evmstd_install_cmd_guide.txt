EVM 社區版的安裝指令修改，
讓 console 上呈現的指令與輸出訊息皆可以記錄於 log 檔案，
安裝記錄檔 將會放在安裝目錄的 evmstd_install_log.txt。


安裝指令修改如下： 
執行第 1 個安裝 Shell Script： 
sudo ./EvMgmtStd_install_01_system.sh 2>&1 | tee -a evmstd_install_log.txt

執行第 2 個安裝 Shell Script：
./EvMgmtStd_install_02_nvm.sh 2>&1 | tee -a evmstd_install_log.txt

執行第 3 個安裝 Shell Script：
./EvMgmtStd_install_03_evmgmt.sh 2>&1 | tee -a evmstd_install_log.txt

檢查安裝記錄檔是否有不可預期的錯誤訊息： 
cat evmstd_install_log.txt | grep -n "error\|warn\|fail"
